### 📥 Inbox 清空了吗？
```dataview
TABLE date AS "日期"
FROM "FPGA开发/00_inbox"
WHERE status = "inbox" AND file.name != "📥 Inbox收集箱"

```

### 🔗 本周新增笔记
```dataview
TABLE file.cday AS "创建日期", tags AS "标签"
FROM "FPGA开发"
WHERE file.cday >= date(today) - dur(7 days)
AND file.name != "定期回顾"
AND file.name != "MOC-FPGA开发大纲"
SORT file.cday DESC
```

### 需要复习的旧笔记（30天未看）
```dataview
TABLE file.mday AS "最后修改", date AS "日期"
FROM "FPGA开发"
WHERE file.mday <= date(today) - dur(30 days)
AND file.name != "定期回顾"
AND file.name != "MOC-FPGA开发大纲"
AND file.name != "📥 Inbox收集箱"
AND file.name != "FPGA学习路线图"
SORT file.mday ASC
LIMIT 10
```
