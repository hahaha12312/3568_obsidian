# 仓库自检

两个维护脚本，改完模板或仪表盘之后跑一下，避免出现「视图空白」「链接点不动」这类问题。

需要 Python 与 PyYAML：

```bash
python -m pip install pyyaml
```

## 校验元数据与 Bases 语法

```bash
python 50-Meta/Scripts/validate_vault.py
```

检查内容：

- 所有 `.base` 文件是合法 YAML，且含 `views`、视图类型有效、排序方向是 `ASC`/`DESC`
- 所有笔记的 frontmatter 是合法 YAML（Templater 变量会被自动替换后再解析）
- `isbn13` 有没有忘记加引号
- `author` / `topics` 是不是列表形式（写成纯文本会让 Bases 反查失效）
- 笔记里内嵌的 ` ```base ` 代码块语法是否正确
- `.obsidian/*.json` 是否为合法 JSON

## 检查断链

```bash
python 50-Meta/Scripts/check_links.py
```

检查内容：

- 所有 `[[双链]]` 是否指向真实存在的文件
- `![[某某.base#视图名]]` 里的视图名是否真的在该 `.base` 中定义过

代码块、行内代码和 HTML 注释里的内容会被跳过，所以文档里的示例写法不会被误报。

## 常见报错

| 报错 | 原因 |
| --- | --- |
| `isbn13 must be quoted` | YAML 把长数字当成了数值，加引号 |
| `author must be a list` | 写成了 `author: 岸见一郎`，应该用 `- "[[岸见一郎]]"` 列表形式 |
| `bad view anchor` | 嵌入时写的视图名和 `.base` 里的 `name` 对不上 |
| `broken link` | 指向的笔记还没建，或者改过文件名 |
