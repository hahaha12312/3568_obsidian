# 工作流

> 这个库的方法论骨架是 **Zettelkasten 的「文献笔记 → 永久笔记」两级结构**，
> 外面套一层 **LYT 的 MOC 导航层**。
>
> 为什么不用 PARA：PARA 是按「项目/行动」组织的，而你的场景没有项目，只有理解的积累。
> 为什么不用渐进式总结：它依赖在数字文本上分层高亮，而你的摘抄是手写的，没有可分层的文字。

## 一张图看懂

```
读书（电纸书/纸质书）
      │
      │ 手写
      ▼
  GoodNotes ──导出PDF──▶ OCR ──▶ Attachments/Books/
                                      │
                                      │ excerpt_pdf 双链
                                      ▼
                          10-Sources/Books/《书名》.md    ← 文献笔记，一本书一则
                                      │
                                      │ 逐条提炼（PDF++ 摘录 → 自己的话）
                                      ▼
                          20-Notes/《一个完整的主张》.md   ← 永久笔记，一个想法一则
                                      │
                                      │ based_on:: / see:: / used_in::
                                      ▼
                          30-Maps/《XX MOC》.md           ← 地图，负责导航
                                      │
                                      ▼
                            回顾 · 重读 · 与 AI 对话
```

## 五个阶段

### 1. 捕获：把手写摘抄搬进来

读完一本书之后（不要边读边搬，会打断阅读）：

1. GoodNotes 导出该书笔记为 PDF
2. **确认是否可选中文字**：在 Obsidian 里打开，试着选一段字。选不中就要 OCR，见 [[03-GoodNotes与OCR]]
3. 放进 `Attachments/Books/`，命名为 `书名-摘抄.pdf`
4. 用豆瓣插件在 `10-Sources/Books/` 建图书笔记，或直接套用 [[图书笔记]] 模板
5. 在 frontmatter 的 `excerpt_pdf` 里用双链指向这个 PDF

> 为什么用双链而不是纯文件名：这样图书笔记会成为 PDF 的反向链接，你在 PDF++ 里读 PDF 时，侧边栏能直接跳回笔记。

### 2. 摘录：把 PDF 里的内容搬进笔记

在 Obsidian 里打开 PDF，左右分屏，右边是图书笔记的 `## 摘录`：

- **有文字层** → 选中 → `Ctrl+Shift+C` → 自动粘贴成带页码链接的引用块
- **纯手写没文字层** → PDF++ 矩形选区 → 框住手写段落 → 嵌入成裁图

**关键纪律**：每条摘录下面必须写一句你自己的即时反应。只存不想，等于没存。

### 3. 提炼：这是整个系统的心脏

读完后**一到两周内**（趁记忆还热，但已经冷静下来）走一遍摘录，问每一条：

> 这句话当时为什么让我停顿？

值得回答的，就开一则永久笔记。三条铁律：

1. **原子性** —— 一则笔记只装一个想法
2. **标题是主张** —— 写「一切烦恼都来自人际关系」，不要写「人际关系」
3. **全用自己的话** —— 抄回原文说明还没消化，那是摘录不是提炼

不是每条摘录都要变成永久笔记。**一本书能产出 3-5 则真正的永久笔记就非常好了**，产出 30 则通常意味着你只是在换个地方抄书。

### 4. 连接：让笔记之间产生引力

每则永久笔记底部维护四种关系：

| 字段 | 含义 | 写法 |
| --- | --- | --- |
| `based_on::` | 这个想法来自哪 | `based_on:: [[被讨厌的勇气]]` |
| `see::` | 和哪则笔记有关，**并说明为什么** | `see:: [[课题分离]] 因为它是这条主张的操作化` |
| `term::` | 用到的术语定义在哪 | `term:: [[个体心理学]]` |
| `used_in::` | 这个想法被我用在哪了 | `used_in:: [[某篇文章]]` |

`see::` **必须写理由**。「因为」后面那句话，往往比链接本身更有价值 —— 它记录的是你当时的思考，而不只是一个跳转。

### 5. 回顾：对抗遗忘

| 频率 | 做什么 | 用什么 |
| --- | --- | --- |
| 每天 | 随机抽一则旧笔记读一读 | 随机笔记（核心插件） |
| 每周 | 清空 `00-Inbox`；给孤儿笔记挂 MOC | [[每周复盘]] + [[孤岛笔记.base]] |
| 每月 | MOC 碰撞；处理待回顾的书 | [[每月复盘]] + [[回顾队列.base]] |
| 持续 | 给最好的永久笔记打 `#review` 标签进入间隔重复队列 | Spaced Repetition |

**MOC 的三个阶段**（LYT 方法，frontmatter 的 `phase` 字段跟踪）：

- `gather` 收集 —— 先把相关笔记堆进来，不讲顺序
- `collide` 碰撞 —— **刻意**把看起来无关的两则并排读，逼自己找共同结构。新想法几乎都诞生在这一步
- `navigate` 导航 —— 结构稳定后整理成有层次的索引

一则 MOC 长期停在 `gather`，说明这个主题你还没真正想过。

## 什么进哪个文件夹

| 文件夹 | 放什么 | 是否长期保留 |
| --- | --- | --- |
| `00-Inbox` | 闪念、还没处理的东西 | **否，每周必须清空** |
| `10-Sources/Books` | 图书笔记，一本书一则 | 是 |
| `10-Sources/Articles` | 网上找的资料 | 是 |
| `10-Sources/AI-Dialogues` | AI 对话产出的笔记 | 是 |
| `10-Sources/People` | 作者页 | 是 |
| `20-Notes` | 永久笔记 | 是，**这里是资产** |
| `30-Maps` | MOC 与 Bases 仪表盘 | 是 |
| `40-Journal` | 日记与复盘 | 是 |
| `50-Meta` | 模板与文档 | 是 |
| `Attachments` | PDF、图片 | 是 |

## 关于 AI 生成的 PDF

单独说一下，因为这类内容最容易变成垃圾。规则：

1. 存到 `Attachments/AI/`，在 `10-Sources/AI-Dialogues/` 建对应笔记
2. **默认 `verified: false`**。AI 说的话在核实之前不算知识
3. 笔记里必须写清楚「我当时在困惑什么」—— 这个问题往往比 AI 的答案更值得留存
4. **未核实的内容不允许提炼成永久笔记**。永久笔记是你相信的东西，不是你听说的东西
