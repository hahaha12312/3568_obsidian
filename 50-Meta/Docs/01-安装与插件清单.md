# 安装与插件清单

> 本清单的维护状态核实于 **2026-09-04**，全部通过直连 GitHub 仓库确认。
> 网上大量教程仍在推荐已经死掉的插件，下面「不要装」一节请务必看。

## 一、把仓库变成 Obsidian 库

1. 克隆本仓库到本地
2. Obsidian → 「打开文件夹作为库」→ 选中仓库根目录
3. 弹窗提示启用社区插件时选「是」
4. 逐个安装下面的插件（`.obsidian/community-plugins.json` 已声明好 ID，但**插件本体不在仓库里**，需要自己装）

## 二、核心插件（Obsidian 自带，已在配置里开好）

| 插件 | 用途 |
| --- | --- |
| **Bases** | 数据库视图，本库所有 `.base` 仪表盘的运行基础 |
| 属性 Properties | 编辑 YAML 元数据 |
| 每日笔记 | `40-Journal/Daily`，模板已配好 |
| 随机笔记 | 重新遇见旧笔记，建议绑快捷键 |
| 模板 | 配合 Templater 使用 |
| 关系图谱 / 反向链接 / 出链 | 看连接结构 |
| 书签 | 钉住常用仪表盘 |

> **Bases 是 2025 年下半年新增的核心插件**，它替代了 Dataview。本库不依赖 Dataview。

## 三、必装社区插件

| 插件 | ID | 为什么装 |
| --- | --- | --- |
| **PDF++** | `pdf-plus` | **本库最关键的插件**。见下方专门说明 |
| **Templater** | `templater-obsidian` | 模板里的日期变量靠它渲染 |
| **QuickAdd** | `quickadd` | 一键新建图书笔记/永久笔记/周月复盘 |

| **Spaced Repetition** | `obsidian-spaced-repetition` | 间隔重复，支持**整篇笔记**复习而不只是卡片 |
| **Homepage** | `homepage` | 启动时直接打开 [[首页]] |

### PDF++ 为什么是关键

你的摘抄是**手写**的，导出的 PDF 很可能没有文字层。PDF++ 有一个别的插件都没有的功能：

> **矩形选区嵌入（Rectangular selection embeds）** —— 在 PDF 上框一个方框，直接嵌入成笔记里的实时裁图。

这意味着**即使一个字都识别不出来，你依然能把手写段落精确嵌进笔记里**。

另外 PDF++ 的设计哲学也值得一提：它把标注存成**纯 Markdown 链接**，而不是私有 JSON。作者原话是「即使这个插件哪天不工作了，只要 Obsidian 还在，你的标注就还在」—— 对一个要用十年的第二大脑，这点很重要。

**建议配置**：
- 给 `复制并自动粘贴选区链接` 绑定 `Ctrl+Shift+C`
- 打开 `Toggle "select text to copy" mode`，选中即复制，不用按快捷键
- 设置链接复制模板，让摘录自动带上页码：
  ```
  > {{text}}
  > —— [[{{file.basename}}|p.{{page}}]]
  ```

## 七、建议的手动设置

打开 Obsidian 设置，按下面调整（部分已经写进 `.obsidian/app.json`）：

- **文件与链接 → 新附件默认位置** → 「指定的文件夹」→ `Attachments/_inline`
  （GoodNotes 的书籍 PDF 手动放进 `Attachments/Books/`，方便批量 OCR）
- **文件与链接 → 新建笔记存放位置** → `00-Inbox`
- **外观 → 打开时显示** → 用 Homepage 插件指向 `30-Maps/首页`
- **快捷键** → 给「随机笔记」和 PDF++ 的复制链接命令各绑一个
- **Templater → 模板文件夹** → `50-Meta/Templates`，并打开「触发 Templater on new file creation」
