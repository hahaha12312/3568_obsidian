## 一、这个月读完了什么

```base
filters:
  and:
    - type == "book"
    - 'status == "finished"'
    - finished >= today() - "1M"
views:
  - type: table
    name: 本月读完
    order:
      - file.name
      - author
      - rating
      - finished
```

## 三、MOC 推进

> 对每则停在 `gather` 阶段的 MOC 做一次「碰撞」：随机挑两则看起来无关的笔记并排读，问自己它们有没有共同的底层结构。

```base
filters:
  and:
    - file.hasTag("type/moc")
views:
  - type: table
    name: MOC 状态
    order:
      - file.name
      - phase
      - last_reviewed
    sort:
      - property: last_reviewed
        direction: ASC
```

## 四、哪本书真的改变了我

> 看「被永久笔记引用次数」排名，而不是看评分。评分是当下的情绪，引用数是长期的影响。
