## 一、清空收件箱

> 目标：`00-Inbox` 归零。每条要么提炼成笔记，要么删掉。收件箱是中转站，不是仓库。

```base
filters:
  and:
    - file.inFolder("00-Inbox")
    - file.ext == "md"
views:
  - type: table
    name: 待处理
    order:
      - file.name
      - file.ctime
    sort:
      - property: file.ctime
        direction: ASC
```

## 二、本周提炼了什么

```base
filters:
  and:
    - file.hasTag("type/permanent")
    - file.ctime >= today() - "7d"
views:
  - type: table
    name: 本周新增永久笔记
    order:
      - file.name
      - topics
      - file.ctime
    sort:
      - property: file.ctime
        direction: DESC
```
