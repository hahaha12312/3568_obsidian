# 读书笔记库 · 第二大脑

一个 Obsidian 仓库，用来存放读书摘抄、查找的资料和 AI 对话产出，并把它们提炼成能长期复用的知识。

> 目标不是「存下来」，而是**让当时心头一震的东西，三年后还能被找到、被想起、被用上**。

## 快速开始

1. 克隆本仓库，用 Obsidian 「打开文件夹作为库」选中根目录
2. 按 [`50-Meta/Docs/01-安装与插件清单.md`](./50-Meta/Docs/01-安装与插件清单.md) 装插件
3. 打开 [`30-Maps/首页.md`](./30-Maps/首页.md) 作为日常入口
4. 通读 [`50-Meta/Docs/02-工作流.md`](./50-Meta/Docs/02-工作流.md)，这是整个库的使用说明

## 目录结构

```
00-Inbox/              闪念与未处理的东西（每周必须清空）
10-Sources/            文献层 —— 别人说的
├── Books/             图书笔记，一本书一则
├── Articles/          网上找的资料
├── AI-Dialogues/      AI 对话产出
└── People/            作者页
20-Notes/              永久笔记 —— 我自己想明白的（这里是资产）
30-Maps/               MOC 地图 + Bases 仪表盘
40-Journal/            日记、周复盘、月复盘
50-Meta/
├── Templates/         模板
└── Docs/              本库的使用文档
Attachments/
├── Books/             GoodNotes 手写摘抄导出的 PDF
├── Research/          资料
├── AI/                AI 对话导出的 PDF
└── _inline/           笔记内嵌图片
```

## 核心流程

```
读书 → GoodNotes 手写 → 导出 PDF → OCR → 图书笔记 → 提炼永久笔记 → 挂进 MOC → 回顾 / 与 AI 对话
       └── 原始档案 ──┘              └────────── 可对话的资产 ──────────┘
```

方法论骨架是 **Zettelkasten 的「文献笔记 → 永久笔记」两级结构**，外面套一层 **LYT 的 MOC 导航层**。
不用 PARA（它是按项目组织的，而这里没有项目只有理解的积累），不用渐进式总结（它依赖数字文本分层高亮，
而手写摘抄没有可分层的文字）。

## 三条不能破的纪律

1. **收件箱每周清零** —— `00-Inbox` 是中转站不是仓库
2. **永久笔记标题必须是完整主张** —— 写「一切烦恼都来自人际关系」，不要写「人际关系」
3. **`see::` 链接必须写理由** —— 「因为」后面那句话比链接本身更值钱

## 技术选型说明

选型核实于 2026-09-04，均通过直连仓库确认维护状态。**很多流行教程推荐的插件其实已经死了**：

| 用什么 | 而不是 | 原因 |
| --- | --- | --- |
| **Bases**（官方核心插件） | Dataview | Dataview 停更 17 个月，662 个未处理 issue |
| **PDF++** | Annotator | Annotator 停更约 2.7 年；PDF++ 标注存纯 Markdown 不会丢 |
| **核心每日笔记 + QuickAdd** | Periodic Notes | Periodic Notes 停更约 2 年 |
| **Local REST API 内置 MCP** | 各种第三方 Obsidian MCP server | 官方已表态第三方「没有必要」；`obsidian-mcp-tools` 作者已归档 |
| **OCRmyPDF**（外部工具） | Obsidian OCR 插件 | 插件不写入 PDF 文字层，Obsidian 搜索和 AI 都读不到 |
| **豆瓣插件** | Book Search | Book Search 走 Google Books，中文书元数据差 |

### 为什么 PDF++ 是关键

摘抄是**手写**的，导出的 PDF 常常没有文字层。PDF++ 的**矩形选区嵌入**可以在 PDF 上框一个方框、
直接嵌入成笔记里的实时裁图 —— **哪怕一个字都识别不出来，手写段落照样能精确引用**。
这是别的插件都没有的能力。

## 关于 git

- `.obsidian/` 里的插件声明、快捷键、外观**会入库**，换电脑一键还原
- 每设备的 UI 状态、缓存、含 API Key 的插件数据**已排除**，见 `.gitignore`
- GoodNotes PDF 直接入库即可，**不需要 git-lfs**（写完就不改的二进制文件普通 git 处理得很好，
  而 GitHub LFS 免费额度只有 1 GB，很容易撑爆）。用 [附件管理.base](./30-Maps/附件管理.base) 盯着体积
